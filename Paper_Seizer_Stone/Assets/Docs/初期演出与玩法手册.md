# 初期演出与玩法手册

`Assets/Scenes/BasicBattle.unity` 已绑定独立的 `TutorialOverlay` 预制体。每次新冒险重新播放整套引导，各节点在本次冒险内只完成一次；失败后重新开始会重置。手动查阅手册不会提前消耗自动引导。

## 演出顺序

1. 首场睁眼、对焦和 HUD 入场完成后，对手说“醒了？欢迎来到牌桌。”。关闭苏醒动画配置时，仍然播放打招呼。
2. “先抽四张牌。”后播放四张发牌；第四张完成后说“我可以允许你再抽一张。”，再发第五张。双方发牌完成后打开基础对抗页，合上后说“选好四张，摆到台上去。”。
3. 玩家首次填满四个槽位，实际落牌与盖牌动画结束后说“摆好了就按铃。”。取回或重摆卡牌不会重复播放。
4. 首次有效按铃，布阵确认演出完成后、揭牌前，说“你这就打算开牌了？”“别急，我们赌点更有意思的。”，打开作弊页；关闭后继续原揭牌流程。
5. 玩家首次中弹且存活，在受击画面和机位恢复后说“你还活着啊。”“再挨一枪，你就真完蛋了。”，打开生命页。如果同一批射击同时杀死敌人，则对白和生命页都推迟到下一次非致命受伤，不标记为已完成；玩家死亡时不播放幸存台词。
6. 敌人首次死亡，在倒地过程中说“呃，好吧。”，自动停留后继续；角色等待台词结束再隐藏，不需要点击继续。非致命中枪不触发此节点。
7. 首次胜利的商店铺毯、物品和钱包入场完成后，无对白，打开商店页。
8. 首次出现有效刻印供应时，无对白，打开刻印页，正常对应第二次胜利后的商店。从烧牌、检视和刻印界面返回同一家商店不会重复触发。
9. 本次冒险首次进入头目战时，桌面和对手入场完成后、第一回合发牌前，按顺序说“啧，你运气真够好的。”“来认真赌一局吧。”“我还是会给你第二次机会。”“当然，我也会给我自己第二次机会。”。四句全部结束后，场景 Light 的灯光瞬间变红，再开始对局。每次头目战都会转红，四句台词每次冒险只播放一次；战斗结束恢复原色。

第一轮规则层仍然一次计算玩家抽五张牌，控制器只在现有逐张事件演出之间停顿，没有改动规则、抽牌顺序或战斗随机序列。后续回合和后续战斗继续使用原有发牌流程。

## 字幕、声音和配置

配置：`Assets/Game/Data/Tutorial/OpeningTutorial.asset`。

- `sequences`：按 `TutorialNode` 保存固定节点。`lines` 中编辑台词、逐字速度、可选整句 `voice`，以及全文显示后的自动停留时间；`openManual` 和 `page` 决定对白结束后是否打开指定页。
- `pages`：基础对抗、作弊、生命、商店、刻印五类说明。使用 `ManualPage` 标识定位，不依赖配置数组顺序。正文已采用用户确认的五段教程文案。
- 未指定整句语音时，使用 `speechBlips` 内的四份自制机械短音。采用轻微随机音高、发声间隔限制和中文标点停顿；标点和空白不发声。清空短音数组即可只保留字幕。机械短音位于 `Assets/Game/Audio/Dialogue/`，没有真人录音。
- 替换录音时，将 AudioClip 拖入对应句子的 `voice`，该句自动改播完整语音。语音音源独立保存在预制体中，不占用普通音效池；音量遵循总音量和音效设置，中断时停止发声。
- 从项目已有 `Text Animator for Unity 2.3.2.unitypackage` 展开了 Runtime 和运行时 Attributes，没有导入示例场景或安装窗口。字幕使用 `TextAnimator_TMP`，默认带轻微颤抖，本次略微加强强度；配置中可写 `<shake>文字</shake>`，可用 `a` 调节幅度，保留逐句标签设置。抖动资源为 `Assets/Game/Data/Tutorial/DialogueShake.asset`，数据库为同目录 `DialogueBehaviors.asset`，全局设置保存于 `Assets/Resources/TextAnimatorSettings.asset`。

商店复用同一套底部字幕和打字机效果，商品价格与刻印状态文字对象保留在预制体中但关闭显示；卡牌自身文字、贴图及悬停卡图说明继续保留。商店无悬停时不显示普通操作提示，各物件按以下内容显示：

- 火盆：“删除一张牌 X筹码”。
- 商品卡牌：“购买XX X筹码”。
- 持有牌组：“你有 X 张牌”。
- 刻印槽：“为卡牌刻印 \"XX\" X筹码”。
- 筹码不足时点击付费物件：“筹码不足”。

进入烧牌子页面后持续显示“选择卡牌烧毁 X筹码”；进入刻印子页面后持续显示“刻印 \"XX\" X筹码”。X 和 XX 来自实际费用、数量与名称。警告逐字显示并短暂停留后，恢复当前悬停提示或持续提示。返回按钮保留可点击底板，按钮文字默认关闭，只在悬停时通过字幕显示“返回商店”。同一提示持续悬停不会每帧重播打字机。

## 手册和输入

预制体：`Assets/Game/Prefabs/UI/Tutorial/TutorialOverlay.prefab`。

右上角“玩法手册”常驻，支持五个分类直接跳转、上一页、下一页，以及左右方向键；“合上手册”、右上角入口或 Esc 关闭。尚未触发的说明也可主动查阅。动作或转场中点击入口会记录请求，在安全结束当前动作后打开。

手动打开和教学自动打开共用快速展开动画：从右上角“玩法手册”按钮的实际中心出发，以12%比例、全透明状态开始，在0.22秒内移动到面板原有中心位置、放大并淡入，末尾减速。关闭用0.16秒反向收回按钮中心并缩小淡出，直到动画结束后才隐藏面板和解除底层输入锁；仍等待关闭输入释放，避免操作穿透。起止位置依据当前UI坐标计算，适配Canvas缩放和不同分辨率，不写死屏幕像素。

分类、上一页、下一页和方向键翻页共用0.14秒的内容过渡：标题、正文、页码先用一半时间淡出，在透明时替换内容，再用另一半时间淡入。底层面板、分类和翻页按钮不参与内容淡化。翻页期间暂时禁用页导航，关闭仍可使用；展开和收回期间不接受重复操作。全部动画使用非缩放时间，取消演出或停用组件会恢复面板原始位置、比例和内容透明度，避免再次打开时残留动画状态。

动画参数位于预制体根节点的 `TutorialDirector`：`manualOpenSeconds`（0.22）、`manualCloseSeconds`（0.16）、`manualClosedScale`（0.12）、`pageFadeSeconds`（0.14，总淡出淡入时长）。`RulesManual` 上保存整体 `CanvasGroup`，标题、正文、页码各保存独立的 `CanvasGroup` 并绑定至 `pageContentGroups`，不在运行时创建UI结构。原黑色半透明底板与两侧渐隐样式保留。本次未运行Unity、编译、测试或画面验证，未操作电脑屏幕，也未新增Editor菜单。

说话只在屏幕最下方显示无底板字幕，不显示说话者名称或继续提示，不压暗游戏画面。字幕逐字显示，全文显示后按 `holdSeconds` 自动停留，有整句语音时也会等待语音播放完成，然后自动进入下一句或下一节点；全程不读取点击或回车来推进，也不等待玩家松开按键。默认普通台词全文显示后停留 1 秒，死亡台词停留 0.8 秒。说明页仍需手动关闭。教学手册和说话演出优先于商店普通提示，演出期间底层战斗、商店、烧牌、检视与刻印操作均被锁定；普通商店字幕和警告本身不锁定输入，也不启用教学遮罩。手册关闭后等待关闭输入释放，防止同一次输入顺便按铃或成交，再恢复当前可用商店提示。主动开手册会取消正在拖拽的卡牌并恢复原布局，移到 UI 上松开拖牌也不会操作背后的桌面。

## 编辑预制体

双击 `Assets/Game/Prefabs/UI/Tutorial/TutorialOverlay.prefab` 进入 Prefab 模式：

- `RulesManual`：手册底板、标题、分类、正文、页码、翻页和关闭按钮。
- `BottomSubtitles/AnimatedSubtitle`：贴近屏幕底边的纯字幕，保留 Text Animator；没有对话底板、说话者或继续提示。
- `OpenManual`：右上角常驻入口。
- `InputShield`：覆盖全屏的底层输入遮罩。

手册与字幕根节点默认关闭。编辑时可临时启用对应节点；已保存基础页正文和一句字幕作为编辑预览，运行时仍以 `OpeningTutorial.asset` 中的内容为准。调整后建议恢复面板默认关闭；运行时 Awake 也会初始化显隐。字体、字号、颜色、底板与按钮尺寸、锚点和音源均可直接修改，无需重新生成场景。

CanvasScaler 使用 Expand，以 1280×720 为最小逻辑设计范围，保证超宽屏仍有足够高度显示完整手册。手册正文使用左上对齐，字幕横向居中、纵向靠底，下沿距屏幕 12 个逻辑像素，左右各留 32 个逻辑像素。字幕字号、锚点、颜色可在预制体的 AnimatedSubtitle 上调整；深色描边的宽度、颜色在根节点 TutorialDirector 上调整，运行时使用独立材质，不修改共用字体材质。同时同步 TMP 旧对齐字段，避免导入后覆盖新对齐设置。
