# 音频系统与首批音效

## 配置入口

选择 `Assets/Game/Data/Audio/GameAudio.asset`，在 Inspector 中编辑背景音乐与关键音效。`sounds` 每项用 cue 枚举标识事件，description 说明用途，clips 可放多个变体；volume、pitchRange、minimumInterval、maximumVoices、priority 分别控制基础音量、随机音高、最短间隔、同时播放数与优先级。priority 数值越小越重要。

`Assets/Game/Prefabs/Audio/AudioManager.prefab` 已保存在 MainMenu、BasicBattle 两个场景的根层。AudioManager 单例跨场景保留，重复实例自动退出；直接打开战斗场景同样有音频。Prefab 保存双音乐音源与十二个音效音源，运行时不构造音频节点或场景。

总音量、音乐、音效继续使用主菜单原有滑条和 PlayerPrefs。总音量仅应用于 AudioListener；分类音量仅应用一次。旧主菜单空音乐音源与 TabletopView 的三个空音效槽已由管理器替代。AudioCategoryVolume 保留给以后独立添加的音源，管理器自身音源不需要此组件。

## BGM

采用用户选定的 Kevin MacLeod《Long Note Four》，原始 MP3 位于 `Assets/Game/Audio/Music/Long Note Four.mp3`。主菜单、战斗、商店共用此曲，基础音量分别为 0.29、0.25、0.18。相同曲目只改变音量，切场景和商店不会重新从开头播放；以后为不同情境更换曲目时，使用两个音源交叉淡化。

音乐淡化默认 1.2 秒。射击准备至击发、受击和机位恢复阶段，音乐压到正常音量的 25%，过渡 0.2 秒；恢复后继续原播放进度。MP3 按 Streaming 导入，完整曲目循环播放，未制作新的无缝循环剪辑。

## 首批关键音效

| 事件 | 接入时刻 | 素材 |
| --- | --- | --- |
| CardPickUp | 拖起手牌、烧牌界面选牌 | Kenney Casino Audio 的 card-fan 变体 |
| CardDraw | 逐张抽牌、作弊抽牌 | card-slide 变体 |
| CardPlace | 合法摆牌、换牌、弃牌、商店商品入牌组 | card-place 变体 |
| CardReveal | 正式揭牌翻转中点 | card-shove 变体 |
| CardShuffle | 弃牌洗回抽牌堆 | card-shuffle |
| Bell | 有效确认或跳过时的铜铃按压 | Kenney Impact Sounds 铜铃裁短版 |
| AmmunitionAdd | 实体子弹首次有效碰撞 | 金属碰撞变体 |
| AmmunitionRemove | 快照中子弹减少 | 金属轻响 |
| GunMechanism | 玩家枪械动作轨开始；敌人或回退演出举枪 | Kenney RPG Audio 的 metalLatch |
| GunLoad | 玩家装填子弹动作轨开始 | metalClick / metalLatch 变体 |
| GunEmpty | 规则判定为空枪的击发时刻 | 降调的 metalClick |
| GunFire | 实弹击发，与原枪口闪光同步 | kurt 的 .22 Magnum 实录，裁静音并调整电平 |
| Hit | 击发后 0.08 秒的中弹反馈 | Impact Sounds 的钝击变体 |
| ScoreTick | 四组对位分别计分 | 轻机械点击 |
| ScoreReveal | 计分器数字增长结束 | 自制短提示音 |
| Victory / Defeat | 单场胜利 / 冒险失败事件 | 自制短音型 |
| ChipDrop | 实体筹码首次有效碰撞 | chips-collide 变体 |
| ChipPay | 购买或烧牌的支付批次开始 | chips-handle 变体 |
| CardBurn | 选中的牌抵达火盆 | 自制一次性燃烧纹理 |

筹码和子弹的碰撞发声组件保存在各自 Prefab；每次激活只响一次，避免弹跳和静止接触反复发声。音效池有分类间隔、实例上限与优先级；同时双枪允许两份枪声，枪声优先于一般牌声。音频随机使用独立 System.Random，不消耗战斗随机序列。GunLoad 的两种金属素材是首版替换素材，后续可直接更换成专用左轮装弹录音。

脚步、环境循环、鼠标悬停、转场布料与每种特殊牌的独立声音暂不增加。铜铃、机械声和合成提示音均为首版配置，最终响度与质感待用户试听调整。

## 素材与署名

音效按 Cards、Chips、Revolver、Impacts、Designed 分类保存在 `Assets/Game/Audio/SFX/`。来源和授权位于同目录上级的 `Licenses/`；`Assets/StreamingAssets/ThirdPartyNotices.txt` 将音乐署名及字体、音效授权说明随构建保留。

- BGM：Kevin MacLeod / Incompetech，CC BY 4.0，需要保留署名。
- 纸牌、筹码、铜铃、机械与撞击：Kenney，CC0。
- 枪声：kurt / OpenGameArt Gunshots，CC0。
- ScoreReveal、Victory、Defeat、CardBurn：为项目自制的程序合成初版。

按项目工作规范未运行 Unity 编译、测试、Play 模式或实机音频验证，未操作电脑屏幕。字体样张仅由本地字体文件离线渲染，不代表 TextMeshPro 实机效果。没有添加临时 Editor 下拉菜单。
