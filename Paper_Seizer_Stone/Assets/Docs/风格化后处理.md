# 全局风格化后处理

## 使用

打开 `Tools > 风格化后处理`，在 Game 视图查看当前场景，无需进入 Play。

1. 选择「风格预设」或拖入「预设资源」，立即将预设参数复制到全局工作配置。
2. 修改窗口中的中文参数，Game 视图随操作刷新；可选「同时预览 Scene 视图」。鼠标悬停参数名可查看说明。
3. 按住「查看原画面」暂时旁路整个滤镜，松开恢复。预览开关及原画面对比仅影响编辑器，不会存入构建。
4. 「保存到预设」覆盖当前预设参数；「恢复预设参数」丢弃当前工作调整，重新读取该预设；「另存为新预设」保存独立资源。
5. 「保存当前应用配置」保存当前选择、总开关和工作参数。关闭窗口也会保存工作配置，关闭窗口不会关闭滤镜。

切换预设会替换工作参数。需要保留的调整应先保存或另存。撤销支持参数调整、预设切换和预设覆盖。修改预设 Inspector 只改预设源文件；重新选择或恢复该预设后应用到工作配置。

## 资源与接入

- 预设及全局工作配置：`Assets/Game/Data/PostProcessing/`。
- 运行时配置类型与 Renderer Feature：`Assets/Game/Runtime/Presentation/PostProcessing/`。
- 中文工具窗口及预设 Inspector：`Assets/Game/Editor/PostProcessing/StyleFilterWindow.cs`。
- Shader：`Assets/Game/art/shader/PostProcessing/StyleFilter.shader`。

HighFidelity、Balanced、Performant 三套现有 Renderer 均引用同一 `StyleFilterSettings.asset`，初始选择「01_旧版画插画」。更换质量档位继续使用同一份工作参数。可通过 `settings.parameters` 在运行时代码中调整；切换预设时同时设置 `selectedPreset` 并使用 `preset.parameters.Copy()`，避免修改共享预设。

效果在 `AfterRenderingPostProcessing` 执行，不依赖相机的标准 Post Processing 开关，不新增或修改 Volume。先复制颜色再进行滤镜，保留原图用于整体混合，不在同一纹理上同时读写。支持当前 URP 12 的颜色目标接口，并对 Unity 2022.2 及以后使用颜色目标 Handle 接口；不升级项目依赖。

颜色传递使用 `_BlitTexture` 与 Core 包的全屏三角形顶点函数，不依赖旧式 `CommandBuffer.Blit` 的隐式 `_MainTex` 绑定和网格顶点输入。URP 12 显式绑定输入并进行两次程序化绘制；URP 14 使用 `Blitter.BlitCameraTexture` 和 RTHandle 临时颜色纹理。复制阶段使用独立的原样输出 Pass，滤镜阶段再读取副本；采样尺寸由相机目标描述显式传入。此调整针对场景丢失、只显示灰色颗粒的问题，未更改预设和当前工作参数，未进行编译或画面验证。

默认处理 Game 类型的 Base 相机。Scene 视图由预览选项控制；跳过预览、反射和 Overlay 相机。Screen Space Overlay 的 HUD 在之后绘制，保持清晰；实体卡牌、世界空间文字及由 Base 相机绘制的 Screen Space Camera UI 都参与滤镜。如果未来采用相机堆叠，叠加相机内容不参与本滤镜。

## 初始预设

| 预设 | 组合 | 主要参数 |
| --- | --- | --- |
| 01_旧版画插画 | 柔和色阶、固定细抖色、淡纸纹、冷暖乘色、轻暗角 | 色阶强度0.42，12级，抖色0.3，纸纹0.025，暗角0.13 |
| 02_复古彩色印刷 | 更少色阶、斜向墨点、略暖纸色与暗角 | 色阶强度0.6，7级，网点0.32，间距5.5，角度35度，暗角0.15 |
| 03_粗笔触油画 | 四象限Kuwahara保边平滑、轻色阶、淡表面纹理 | 平滑0.65，半径2像素，色阶强度0.12，18级，暗角0.12 |

预设是供美术调整的起点，尚未通过实际画面调优。所有风格参数均可自由组合，不受预设类型限制。整体强度0返回原画面；总开关关闭或整体强度0时不提交滤镜Pass。

## Shader 参数

| Shader 参数 | 分量 / 用途 |
| --- | --- |
| `_Style` | 整体强度、色阶强度、每通道色阶数、抖色强度 |
| `_Print` | 网点强度、网点间距、网点角度（弧度）、抖色尺寸 |
| `_Surface` | 油画平滑强度、采样半径、纸纹强度、纸纹尺寸 |
| `_Grade` | 曝光档数、对比度/100、饱和度/100、冷暖偏移/100 |
| `_Vignette` | 暗角强度、柔和度、中心X、中心Y |
| `_InkColor` | 网点油墨颜色 |
| `_ShadowColor` / `_HighlightColor` | 暗部 / 亮部乘色 |
| `_SplitTone` | 暗亮乘色混合强度 |
| `_VignetteColor` | 暗角颜色 |

处理顺序：保边平滑 → 曝光与调色 → 色阶与抖色 → 半色调网点 → 纸纹 → 暗角 → 与原图混合。调色与印刷操作在显示颜色空间中完成，曝光在线性空间中调整，输出回到项目颜色空间。色阶按RGB通道量化，网点按亮度控制覆盖率；纸纹与抖色都固定在屏幕，不随时间跳动。纸纹由噪声生成，不需要外部纹理。最终风格颜色限制在0～1，适合普通显示输出，不保留HDR超亮值。

点纹、纸纹以1080p为尺寸参考，适应Game视图缩放；油画半径为实际渲染像素。油画是四个象限中选择颜色方差最小区域的均值，强度0时完全跳过，半径1～4，每像素最多100次区域采样。建议从半径2开始。所有滤镜均作用于实体卡面，小字变糊时先降低油画强度和半径；网点过密时降低网点强度。

工具没有创建临时生成菜单、场景对象或运行时场景结构。本次未运行编译、测试、编辑器试玩或操作电脑屏幕，未产生需要清理的测试缓存。
